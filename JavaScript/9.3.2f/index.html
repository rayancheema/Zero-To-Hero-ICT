9.3.2e: Be able to program functionality: subprograms

Subprograms (functions) are used where code is repeated again and again, therefore we can make a function which can be called, reducing the need for repeated code and making the code effecient and clean.

The syntax for setting up a function/subprogram is as follows:

function myFunctionName(parameter1, parameter2) {

// Code to be executed

}

For Example:

function myFunctionName(num1, num2) {

Let num3: num1+num2;

return num3;

}
